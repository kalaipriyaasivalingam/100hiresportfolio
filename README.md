## Challenges & How I Solved Them

**Challenge 1 — Multiple Claude Code extensions in marketplace**
Several extensions had similar names. I identified the correct one
by verifying the publisher was Anthropic before installing.

**Challenge 2 — Git not installed on my computer**
The terminal showed an error when I tried to clone.
I solved this by installing GitHub Desktop which handled
the cloning without needing Git in the terminal.

## What I Learned

This process introduced me to developer workflows I hadn't
used before as a marketer — version control, repositories,
and AI-powered coding tools. It showed me how tools like
Claude Code are becoming essential across all roles,
not just engineering. Being able to navigate these tools
confidently is increasingly important in modern marketing roles.
